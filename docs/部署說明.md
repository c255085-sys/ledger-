# 第一次部署到 GitHub Pages

這份說明會帶你把空白記帳本放到網路上。完成後，任何人都能用網址看到公開頁面。

## 1. 先檢查要公開的檔案

GitHub Pages 的 repo 是公開的，放進去的內容任何人都看得到。上傳前請逐一檢查檔案：

- 不要放 API key、密碼或 `.env` 檔。搜尋 `AIza`、`apiKey`、`API_KEY`、`Bearer`，確認沒有真的金鑰。
- 不要放自己的記帳資料、匯出的 CSV 或含個人資料的截圖；範例請用假的資料。
- `.gitignore` 會幫忙略過常見的暫存檔和備份檔，但仍要親自檢查準備上傳的檔案。

## 2. 在 GitHub 建立公開 repo

1. 用瀏覽器開啟 [github.com](https://github.com)，登入帳號；沒有帳號就先註冊。
2. 點右上角的 **＋**，選 **New repository**（新增儲存庫）。
3. 在 **Repository name**（儲存庫名稱）輸入 `ledger`。名稱可以自訂，等等網址也會跟著改。
4. 選 **Public**（公開）。
5. 按 **Create repository**（建立儲存庫）。

## 3. 用網頁上傳檔案

1. 在新 repo 頁面點 **Add file**（新增檔案），再選 **Upload files**（上傳檔案）。
2. 把專案要公開的檔案拖進頁面，或按 **choose your files**（選擇檔案）。確認沒有 API key、真實記帳資料、CSV 或本機備份檔。
3. 在頁面下方的 **Commit changes**（提交變更）區塊，寫一則中文訊息，例如「上傳記帳本空白頁」。提交訊息是在說明這次存了什麼。
4. 再檢查一次準備提交的檔案和內容：沒有 key，也沒有真實資料。確認後按 **Commit changes**。

## 4. 開啟 GitHub Pages

1. 在 repo 上方點 **Settings**（設定）。
2. 左側選單找到 **Pages**。
3. 在 **Build and deployment**（建置與部署）下，Source 選 **Deploy from a branch**（從分支部署）。
4. Branch 選 **main**，資料夾選 **/(root)**，再按 **Save**（儲存）。
5. 等幾分鐘，回到 Pages 設定頁。看到 **Your site is live at**（你的網站已上線）和網址，就表示 GitHub 已開始提供網頁。

## 5. 找到網址並用手機確認

網址通常是：

`https://你的GitHub帳號.github.io/ledger/`

把「你的GitHub帳號」換成自己的帳號名稱。如果 repo 取了別的名字，也要把 `ledger` 換成 repo 名稱。你也可以直接點 Pages 頁面上 **Your site is live at** 後面的網址。

用手機開啟網址，確認看到「我的記帳本」、網址開頭是 `https://`，而且不是 404 或空白頁。第一次部署可能要等幾分鐘；等一下再重新整理看看。

## 之後更新網頁

有新檔案要上傳時，回 repo 用 **Add file → Upload files**。提交前一樣先檢查沒有 API key、真實記帳資料或不該公開的檔案，並用中文寫提交訊息。
