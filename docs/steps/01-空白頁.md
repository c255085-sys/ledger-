# 第 1 步：建空白頁並部署

> 這份是給阿興看的小方案。看完覺得可以，回一句「可以」，才開始做。
> 只講三件事：這步做什麼、會動到哪些檔案、手機上看到什麼算過關。

## 一、這步做什麼

做一個「只有名字、什麼功能都還沒有」的網頁，放到網路上，讓手機打得開。

1. 我新增一個 `index.html`，打開只會看到五個字：**我的記帳本**。沒有按鈕、沒有輸入框、沒有樣式。
2. 阿興在 GitHub 開一個公開的 repo（就是這個專案在 GitHub 上的資料夾；建議名稱 `ledger`，想改別的也行，網址會跟著變），用網頁的 Add file → Upload files 把 `index.html` 上傳進去。沒有 GitHub 帳號就先註冊一個免費帳號。
3. 到這個 repo 的 Settings → Pages，來源選 `main` 分支、資料夾選 `/ (root)`，按 Save。
4. 等 GitHub 把網頁做出來（通常 1～3 分鐘），網址是：
   `https://<你的 GitHub 帳號>.github.io/ledger/`
   （repo 如果叫別的名字，把網址最後的 `ledger` 換成那個名字。）
5. 手機打開這個網址，看到標題就算這步完成。**做完就停，不往下做。**

為什麼先做這個：先確定「寫好的東西真的放得上網路、手機真的打得開」。這關過了，後面才不會寫了一堆功能卻卡在部署。

這步不會碰到 API key，也不會碰到任何真實記帳資料；`index.html` 裡面只有一個標題，repo 公開給人看也沒關係。

這步**不做**：樣式、JavaScript、Gemini、語音、記帳、PWA、CSV、匯入。也不新增套件、不跑建置。

### 誰做什麼、大概多久

- **我**：新增 `index.html`，內容照第二節；其他檔案不動。
- **阿興**：開 repo、上傳 `index.html`（GitHub 網頁上傳會自動留下一筆存檔紀錄，也就是 commit）、開 Pages、用手機驗收。這幾步要用你的 GitHub 帳號，我沒辦法幫你按。
- **順序**：這步一定要先上傳才看得到畫面，所以是「先上傳、再驗收」。沒過就改到過，不會接著做下一步。這樣可以嗎？
- **時間**：操作約 10 分鐘，等 Pages 約 1～3 分鐘。上傳用電腦瀏覽器比較好按；只有手機的話，GitHub 網頁版也做得到。

## 二、會動到哪些檔案

| 檔案 | 動作 | 內容 |
| --- | --- | --- |
| `index.html` | 新增（這步唯一的新檔案） | 繁體中文網頁，只有「我的記帳本」標題；含一行手機畫面寬度設定（viewport），打開不會縮成很小的字 |
| `CLAUDE.md` | 不動 | — |
| 其他檔案 | 不動 | 這步不加 `style.css`、`app.js`、`manifest.webmanifest`、`sw.js` |

GitHub 上會多一個 repo 和一個 Pages 設定。那不是檔案，但會決定上面的網址。

`index.html` 的內容就這些：`<!doctype html>`、`lang="zh-Hant"`、UTF-8、viewport；`<title>` 和 `<h1>` 都寫「我的記帳本」，畫面沒有別的東西，也不要連 `style.css` 或 `app.js`。檔名一定要叫 `index.html`，不能叫 `index.htm` 或別的名字，不然網址打開會找不到。

## 三、手機上看到什麼才算過關

先關掉 Wi-Fi、用手機行動網路開（這樣才知道別人也打得開），依序確認：

- [ ] 網址開得起來，不是「找不到網頁」，也不是 GitHub 的 404 畫面。
- [ ] 畫面上看得到 **我的記帳本** 這五個字，字的大小正常，不用放大也看得清楚。
- [ ] 網址開頭是 `https://`，瀏覽器顯示安全（小鎖頭），沒有「不安全」警告。
- [ ] 畫面沒有錯誤訊息、沒有一直轉圈、不是一片空白。
- [ ] 按重新整理一次，上面四項還是一樣。

五項都打勾＝過關。有一項沒過，先看下面。

### 沒過時，先自己看這三件事

1. **是不是太早看**：Pages 第一次要 1～3 分鐘，等 3 分鐘再整理一次。
2. **`index.html` 有沒有放對位置**：要在 repo 最外層，不能藏在資料夾裡。
3. **Pages 設定對不對**：Settings → Pages 要是 `main` 分支、`/ (root)`；存檔後頁面上方要出現「Your site is live at …」的網址。
